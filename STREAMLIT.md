# Deploying Auto Object Annotator on Streamlit Community Cloud

1. Open [share.streamlit.io](https://share.streamlit.io/) and sign in with GitHub (`2000pd3rvr`).
2. Create app → repository `2000pd3rvr/auto_object_annotator_0.0.4` → branch `main` → main file `streamlit_app.py`.
3. Choose a subdomain such as `auto-object-annotator`, then deploy.

Live demo: https://huggingface.co/spaces/0001AMA/auto_object_annotator_0.0.4  
Source: https://github.com/2000pd3rvr/auto_object_annotator_0.0.4
